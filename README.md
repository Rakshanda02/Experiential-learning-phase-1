# Experiential-learning-phase-1

## Library Booking App

A Streamlit library dashboard backed by SQLite and a custom hash table. It includes librarian and
student accounts, borrowing limits, automatic late-return fines, reservation queues, and borrowing
analytics.

See [the app README](library_booking_app/README.md) for setup and usage. On first run, create the
librarian account, then students can register or be added by a librarian.
